# 子外掛

## 描述

依賴 Powerhouse 的 WordPress 外掛，如 `power-course`、`power-shop`、`power-contract` 等。透過 WordPress filter/action 向 Powerhouse 註冊產品資訊，並使用 Powerhouse 提供的通用工具庫。

## 關鍵整合點

- `powerhouse_product_infos` filter：子外掛透過此 filter 向 Powerhouse 註冊產品資訊（product_slug、name、link），使授權碼管理頁顯示對應產品
- `powerhouse/option/allowed_fields` filter：子外掛可擴展允許更新的 option 欄位
- `powerhouse/product/get_options` filter：子外掛可擴展商品選項回應
