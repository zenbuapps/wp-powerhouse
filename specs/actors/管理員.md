# 管理員

## 描述

WordPress 管理員，具備 `manage_options` 權限。操作 Powerhouse 後台的所有功能，包括設定、授權碼、資源 CRUD、存取權限管理等。

## 關鍵屬性

- WordPress 角色：`administrator`
- 必要能力：`manage_options`
- 認證方式：WordPress Cookie + `X-WP-Nonce` Header

## 存取路徑

- 後台 URL：`/wp-admin/admin.php?page=powerhouse`
- REST API 基礎路徑：`/wp-json/v2/powerhouse/*`
