## 推斷清單（AI 自行決策的假設）

### API 相關假設

| 假設 | 根據 | 決策 |
|------|------|------|
| `GET /options/upload` 沿用 misc domain | V2Api.php 中有 `register_upload_options_route()` | 歸入 settings domain |
| limit 端點使用 `application/x-www-form-urlencoded` | PHP 使用 `get_body_params()` | 確認為表單資料 |
| `lc/invalidate` 為 public 端點（無需認證） | `permission_callback` 為 `__return_true` | 標記為 public |
| `POST /posts` 使用 multipart/form-data | 有 `get_file_params()` 取圖片 | 確認為 multipart |
| Copy domain 歸入 post/複製文章 | 僅有 `POST /copy/{id}` 一個端點 | 獨立 feature |

### Entity 相關假設

| 假設 | 根據 | 決策 |
|------|------|------|
| WooCommerce 訂單狀態有 7 種 | Feature files 中的 datatable 範例值 | 標記 `?1[假設]` |
| limit_type 有 4 種值 | 程式碼中的 Enum 和 feature 範例 | 標記 `?2[假設]` |
| wc_order_stats 的額外欄位觸發條件 | Report V2Api.php 中的 REQUEST_URI 判斷 | 標記 `?3[假設]` |
| powerhouse_settings 和 powerhouse_license_codes 以虛擬表描述 | 實際儲存於 wp_options（非獨立表） | 以虛擬表格式呈現 |
